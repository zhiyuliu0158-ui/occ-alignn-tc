# 19,894 条 SC-Atlas 数据的 Tc 预测方法与结果

## 1. 结果标识

- 结果名称：SC-Atlas 19,894 条非高压氢化物数据的 Tc 回归
- 数据版本：`OUR_SC_ATLAS_DATA_FINAL_20260810`
- 主结果目录：`aligned_scope_magpie_physical_condition_group_holdout10`
- 模型：XGBoost 回归
- 输入：MAGPIE 成分特征 + 实验条件 + Physical Substrate
- 主要评价指标：非加权 `log1p(Tc)` 空间 R2
- 主要结果：`0.7838 +/- 0.0243`
- 非加权原始 Tc R2：`0.7849 +/- 0.0422`
- 非加权 MAE：`5.7395 +/- 1.5244 K`
- 所有数值均为 10 次严格化学体系分组测试的均值和样本标准差。

## 2. 数据来源和数据层级

原始数据包包含 21,910 条可追溯的完整 ML 记录，以及按“标准化论文标识、标准化化学式和 Tc”三个键去重后的 20,119 条 public-core 记录。本实验采用 20,119 条 public-core 数据，避免同一论文中完全相同的化学式-Tc 记录重复放大模型性能。该去重过程合并了 1,791 条来源记录，涉及 1,511 个重复组。

Materials Project、3DSC、CIF、ALIGNN-DOS、电子 DOS 和声子 DOS 均未参与本次 19,894 条模型的输入。本结果只评价成分及实验条件信息能够达到的 Tc 预测性能。

## 3. 高压氢化物研究范围筛选

为了与此前 12,546 条论文主数据的研究范围一致，从 20,119 条 public-core 数据中剔除了高压氢化物家族：

1. 将含 H 且不含 C、N、O、F、Cl、Br、I 的化学式定义为候选氢化物，避免把有机物、氧化物、氮化物、氢氧化物和卤化物误判为高压氢化物。
2. 压力证据大于 5 GPa 的候选氢化物被直接剔除。
3. 对压力缺失的候选氢化物，只有 H/非 H 原子数比不小于 2 时才按超氢化物处理；本数据中没有记录因该规则被单独剔除。
4. 如果某个氢化物化学体系已经具有直接高压证据，则同一化学体系的其他氢化物记录也一并从本研究范围中剔除。

实际筛选结果如下：

| 项目 | 数量 |
|---|---:|
| 筛选前记录 | 20,119 |
| 剔除记录 | 225 |
| 直接具有大于 5 GPa 压力证据 | 211 |
| 压力缺失且由超氢化物计量推断 | 0 |
| 同化学体系家族扩展剔除 | 14 |
| 剔除化学体系 | 23 |
| 剔除规范化化学式 | 39 |
| 最终记录 | **19,894** |

这一操作是研究范围限定，不应描述为“225 条错误数据”。

## 5. 输入特征

模型共使用 177 个输入特征，不进行基于全数据的特征筛选。

### 5.1 MAGPIE 成分特征

共 131 个特征，由规范化材料化学式计算，包括：

- 元素组成范数和可形成离子化合物指标；
- 原子序数、Mendeleev 数、原子质量、周期和族；
- 共价半径、价电子和未填充电子轨道统计；
- 基态体积、基态带隙、基态磁矩和空间群编号等元素属性统计；
- 各属性的加权均值、最大值、最小值、极差、偏差和众数等聚合量。

### 5.2 压力和磁场特征

共 5 个特征：

1. `pressure_GPa`
2. `magnetic_field_T`
3. `pressure_missing`
4. `magnetic_field_missing`
5. `is_high_pressure_gt1GPa`

压力或磁场缺失时保留 NaN，并提供独立缺失标记；只有原始数据明确记录为 0 时才使用物理零值。

### 5.3 Tc 测量判据

使用 4 个 one-hot 特征：onset、midpoint、zero 和 unknown。

### 5.4 Physical Substrate 特征

共 37 个特征，包括 6 个状态特征和 31 个物理描述符：

- 衬底已知、未知、不适用、适用、薄膜样品和化学式可解析状态；
- 元素数、总化学计量数、组成熵和 O/F-Cl-Br-I/N/C 原子分数；
- 氧化物、卤化物、氮化物、碳化物、硫属化物、ABO3 类钙钛矿、元素金属和第 14 族元素衬底标记；
- 衬底原子序数、原子质量、熔点、共价半径、电负性、基态体积、基态带隙、空间群以及价电子分数等聚合属性。

`sample_form` 不作为独立 one-hot 输入。它只用于确认 thin_film、monolayer 和 interface 记录的衬底字段在物理上“适用”，避免把衬底缺失错误解释成块体样品的“不适用”。

完整 177 个特征名称保存在 `paper_feature_list_19894.csv`。

## 6. 模型与目标变量

采用 XGBoost 3.2.0 的 `XGBRegressor`。每个训练折先用仅在该训练折拟合的 `StandardScaler` 标准化输入，再训练梯度提升树。模型的实际默认参数为：

| 参数 | 数值 |
|---|---:|
| booster | gbtree |
| objective | reg:squarederror |
| boosting trees | 100 |
| max_depth | 6 |
| learning_rate | 0.3 |
| min_child_weight | 1 |
| subsample | 1.0 |
| colsample_bytree | 1.0 |
| gamma | 0 |
| reg_alpha | 0 |
| reg_lambda | 1 |
| max_bin | 256 |
| grow_policy | depthwise |
| tree_method | auto，CPU quantile-hist updater |
| early stopping | 未使用 |
| n_jobs | 4 |
| 每折随机种子 | 58 + repetition |

模型不是直接拟合原始 Tc，也不是直接拟合 log1p(Tc)，而是使用项目既有的受限反双曲正弦变换：

```text
z = asinh(max(Tc, 0) / 2) / [10 * asinh(1 / 2)]
```

预测后执行逆变换：

```text
Tc_pred = 2 * sinh(z_pred * [10 * asinh(1 / 2)])
```

逆变换后的预测限制在 0 到 400 K。论文中的 `log1p R2` 是对最终 Tc 预测在 `log1p(Tc)` 空间重新计算的评价指标，不是模型训练目标。

为降低高频化学式重复测量对训练的支配，每条记录采用公式权重：

```text
w_i = 1 / n(formula_i)
```

主结果使用非加权指标，使每条实验记录在最终评价中具有相同权重；公式加权指标作为辅助结果保存。

## 7. 严格验证方案

采用 10 次 `GroupShuffleSplit`：

- 分组变量：完整化学体系，例如 Ba-Cu-O-Y；
- 每次约 80% 化学体系训练、20% 化学体系测试；
- 随机种子：58；
- 每折训练化学体系：1,375；
- 每折测试化学体系：344；
- 每折训练/测试化学体系交集：0；
- 平均训练记录：16,115.3，范围 14,199 至 17,001；
- 平均测试记录：3,778.7，范围 2,893 至 5,695。

这是比随机逐行划分更严格的外推测试。同一元素体系的不同化学式不会同时出现在训练集和测试集中，因此结果不依赖近重复材料泄漏。

## 8. 评价指标

对每个测试折计算：

- MAE：`mean(|Tc_pred - Tc|)`；
- RMSE：`sqrt(mean((Tc_pred - Tc)^2))`；
- 原始 Tc R2；
- MSLE：`mean((log1p(Tc_pred) - log1p(Tc))^2)`；
- log1p Tc R2：对 `log1p(Tc)` 和 `log1p(Tc_pred)` 计算 R2。

均值后的预测再计算指标与逐折指标均值不是同一统计量。本研究报告的是先在每个测试折独立计算指标，再对 10 个折的指标求均值和样本标准差。

## 10. 与旧版 12,546 条结果的关系

旧版高置信度清洗数据的非加权结果为：MAE `5.690 +/- 1.091 K`、原始 Tc R2 `0.772 +/- 0.056`、log1p Tc R2 `0.779 +/- 0.034`。新版 19,894 条结果相应为 `5.739 +/- 1.524 K`、`0.785 +/- 0.042` 和 `0.784 +/- 0.024`。

新版原始 R2 高约 0.013，log1p R2 高约 0.004，MAE 高约 0.05 K。由于两版数据的记录组成和测试化学体系并不完全相同，这些差值不能解释为配对显著性提升。更稳妥的结论是：在数据量增加约 58.6% 后，模型性能总体保持稳定，并且严格化学体系外推性能没有下降。

## 11. 可直接写入论文的方法描述

> 本研究采用经论文标识、标准化化学式和临界温度三键去重的 SC-Atlas public-core 数据。为与既定研究范围保持一致，进一步剔除具有大于 5 GPa 直接压力证据的高压氢化物及其同化学体系家族记录，最终获得 19,894 条样本，包含 5,049 个模型规范化成分和 1,719 个化学体系。输入特征由 131 个 MAGPIE 成分描述符和 46 个实验条件特征组成，后者包括压力、磁场、缺失标记、Tc 测量判据以及物理化衬底描述符。缺失压力和磁场被保留并通过独立指示变量编码，而未被填充为物理零值。采用 XGBoost 回归模型预测经受限反双曲正弦变换后的 Tc，并使用化学式频次的倒数作为训练样本权重。模型通过 10 次按完整化学体系分组的 80/20 留出测试进行评价，所有划分中训练集与测试集的化学体系交集均为零。

## 12. 可直接写入论文的结果描述

> 在 10 次严格化学体系分组测试中，MAGPIE、实验条件和 Physical Substrate 联合模型取得了 `5.739 +/- 1.524 K` 的非加权 MAE、`10.248 +/- 2.639 K` 的非加权 RMSE和 `0.785 +/- 0.042` 的原始 Tc R2。在对 Tc 进行 log1p 变换后，模型的 R2 为 `0.784 +/- 0.024`，MSLE 为 `0.259 +/- 0.042`。每次划分均包含 344 个完全未在训练中出现的测试化学体系，且训练集与测试集之间不存在化学体系重叠，说明该结果反映了对未知元素体系的严格外推性能，而不是随机逐行划分中的近重复材料插值性能。

## 13. 报告时应说明的限制

1. 本结果不包含晶体结构、CIF、电子结构或声子信息，因此不能解释结构多型或相变对 Tc 的影响。
2. 共有 291 条非空衬底文本不能解析为单一化学式，其衬底状态被保留，但物理描述符为零。
3. 严格化学体系分组比实际应用中的同体系新成分预测更困难，不同测试折的记录数量也会因体系大小不同而变化。
4. 高压氢化物是按研究范围剔除，不代表这些记录本身错误；涉及高压氢化物的结论应使用另行训练的全量 20,119 条结果。
5. 该模型使用 XGBoost 默认树参数，没有在测试折上调参，也没有使用早停。
